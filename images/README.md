# AURA Robotics image assets

This directory contains first-party AURA brand assets and locally hosted product media.

## Local product media naming

Use descriptive, stable names such as:

- `c40-hero-transparent.webp`
- `c40-gallery-01.webp`
- `t10-hero.webp`
- `t10-gallery-01.webp`

Keep image references relative to the site root (for example, `images/c40-hero-transparent.webp`).

## Before adding manufacturer media

Only add KEENON/manufacturer images that AURA is authorized to reproduce on its public website. Keep the original source URL and any required attribution in the asset inventory or page credit. Prefer optimized WebP or AVIF derivatives while retaining a source copy outside the public site if needed.

## Current migration status

- C40 primary/hero image: locally hosted as `c40-hero-transparent.webp`.
- Other product catalog images and several product-detail galleries still reference the KEENON image host and are pending migration.
- The homepage family slide and the globe texture still depend on external KEENON-hosted media.
